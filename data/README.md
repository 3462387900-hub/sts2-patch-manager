# 公共 MOD 来源索引（首批数据）

本目录用于保存《杀戮尖塔 2》（Steam AppID `2868840`）的 **MOD 内部 ID → Steam Workshop ID** 对照表。该文件仅记录来源，不包含 MOD 文件本体或更新校验基线。

## 数据来源和质量标记

- `workshop-source-index.json` 首批收录 **45 条**，由用户通过尖塔修补站 v0.14.5 Beta 1 的本地来源绑定及导出功能提交，经结构与唯一性检查后收录。
- 全部记录均保留 `verification: "local_binding"`，表示**本地曾经人工绑定**，而不是远端内容身份/版本已经经过技术验证。
- 已检查 `schema`、`app_id`、字段类型和长度、Workshop ID 为非零数字、MOD ID（忽略大小写）唯一、Workshop ID 唯一。
- 已做公开 Steam 条目抽样核对，**没有逐条验证全部 45 个 Workshop 内容清单**。因此不要把数据直接升级为 `verified`、`trusted` 或任何意味着已签名/已校验内容的标记。

## 后续管理器使用规则

1. 本索引不是下载器，不应自动下载、替换、启用或停用任何 MOD；修改文件必须继续走用户确认及已有的哈希、备份、回滚机制。
2. 用户自己手动确认的关联优先于公共索引；公共索引不得静默覆盖本地已有来源。
3. **仅凭 MOD ID 相同不能认定 Workshop 文件与用户本地版本完全一致。** 匹配时还要核对名称、作者和远端候选；冲突、复用或证据不足的条目必须先让用户确认。
4. 下载索引时检查 schema、app_id、ID 合法性、重复冲突和大小上限；不可将远端索引当作任意本地文件路径或可执行命令。
5. 云端缓存可以用于展示来源候选，但不得由本索引生成或覆盖版本校验的 manifest/本地文件指纹基线。网络不可用时维持当前本地绑定。
6. 此数据文件不会被当前 v0.14.5 Beta 1 管理器自动读取；公共索引下载、离线缓存和匹配将在后续独立版本实现。

## 建议复核的条目

- `RemoveMultiplayerPlayerLimit` → `3809094500`：所指 Steam 创意工坊页面描述为基于原版的第三方更新构建；同一个内部 MOD ID 可能对应不同分支或打包，请在将来自动关联前再次核对。
- `CyanrainNymphBeta` → `3754068303`：提交内容的作者字段为泛化的 `Author`，不能凭作者字段独立验证身份。

其他条目也不应因为未出现在上面就推定已逐项远端验证。

## 维护方式

由维护者审核新导出的 JSON 后更新。每次修改需检查已有 ID 冲突、重复 Workshop ID、远端可能的重发版，以及是否混入本地路径、日志、账号或其他个人信息。
