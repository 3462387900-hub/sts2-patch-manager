# 尖塔修补站 v0.11.3

本版重点优化修复补丁的健康状态、判断依据，以及 MOD 更新后的长期复核提醒。

- 在「模组管理」→「修复补丁」列表及详情中显示最近一次有效的补丁健康判断，如「未检查」「需重新检查」「已知构建匹配」「需要复核」「上游修复已验证」。
- 新增「查看依据」页面：包含本地安装/文件状态、扫描时间、相关 MOD 的更新提醒、上游审核状态、精确 DLL SHA-256 与可打开的来源链接；没有证据时会明确说明不能推断旧补丁已不需要。
- 从修复补丁列表或依据页面发起健康检查后，可留在原页面查看结果，不必往返跳转。
- 未核对的 MOD 更新在重复扫描后继续保留。经用户明确确认、且再次验证文件没有变化后，才允许清除这项提醒。确认仅作用于管理器内部记录，不修改游戏文件，也不构成上游 Bug 已修复的认证。
- 游戏目录切换、MOD 启停和补丁文件操作仍会使旧健康结果失效；扫描任务结束前也会核对环境是否已经切换或被标记失效。
- 继续使用 v0.11.2 的普通 MOD/修复补丁分离布局，以及原有的安装事务锁、预览、SHA-256 和可恢复停用机制。

注意：健康结果属于最近一次扫描时的快照，外部工具更新 MOD 后需重新检查。当前上游确认记录可能为空；不会仅凭版本号或提示文本自动停用补丁。本版不修改任何游戏补丁载荷、第三方 MOD 或玩家存档。
