# 尖塔修补站 v0.14.6 Beta 1 · ATLAS 原生 WPF 测试版

**这是 GitHub Pre-release 测试版，不是正式稳定版。** 本版用于在实际 Windows 电脑上验收 PR39 的 ATLAS 原生界面。稳定版 `manager-update.json` 不变；仅选择「测试版 Beta」更新通道的用户会看到此版本。

## 主要内容

- 将「ATLAS」作为可切换的 **原生 WPF 工作台**：总览、模组库、修复中心、更新中心、下载中心与设置。无需 WebView2。
- 模组库提供可筛选、排序、勾选的卡片/虚拟化列表；卡片每页最多 24 张，输入停止约 180ms 后执行搜索重绘，支持跨页全选筛选结果。
- 更新中心每页最多 24 张卡片，支持来源筛选与上次缓存状态。打开更新中心不会强制启动联网检查。
- 下载中心支持输入 Workshop 数字 ID/Steam 或尖塔补给站链接，预览前先验证输入；GitHub 和 ZIP 下载继续复用现有安全预检。
- 修复补丁与普通 MOD 分区，显示健康状态、孤立补丁自动停用设置；保留旧版工作台、修复来源/详情/回滚等原有业务流程。
- 改善 Windows 大窗口列表高度、窗口伸缩与卡片换列，减少后台扫描的重复刷新和旧页面抢占导航。
- MOD 启停按钮在点击时重新核对最新清单、目录及启停状态；不允许旧卡片和缓存行绕过原来的文件安全预检。

## 如何通过管理器更新

1. 在现有管理器进入 **检查更新**（或「设置 → 管理器更新」）。
2. 更新通道切换为 **测试版 Beta**，主动点击「检查更新」。
3. 选择 **v0.14.6 Beta 1**，先查看更新内容，然后选择下载并更新。
4. 更新完成后选择 **ATLAS 原生**主题测试。保留经典和新版工作台作为回退入口。

建议测试前备份自己的管理器数据和 `mods` 目录；不在未经备份的真实目录上尝试批量更改/回滚。若旧管理器还不支持 Beta 通道，可从本 Release 下载 ZIP 解压到新文件夹，运行 `00-启动尖塔修补站.exe` 或 `SpirePatch.exe`。

## 已验证范围与限制

- GitHub Windows CI 使用隔离游戏样本构建与自动化检查；该结果不等于真正 1440p/4K、多显示器或百/千 MOD 的硬件性能数据。
- 下载、安装、更新、启停和补丁回滚保留现有确认与安全检查；**真实下载/回滚操作仍需要玩家手工验收**。
- 本 Beta 以 **v0.14.3 稳定主线 + PR39 ATLAS 分支**为基础，未合入独立 v0.14.4/v0.14.5 Beta 分支的部分旧布局附加功能（例如旧工作台人工 Workshop 来源导出）；如依赖这些 Beta 功能，请先保留旧版安装文件。ATLAS 模组库仍提供未绑定 Workshop ID 筛选。
- 仅用于反馈 ATLAS 的界面、响应、功能安全与兼容性问题；不会替换稳定版自动更新索引，不表示 PR39 已合并或可以正式发布。

问题反馈：请提供当前版本、Windows 分辨率/DPI、MOD 数量、复现步骤及脱敏截图。验收清单见 `docs/ATLAS-PR39-实机验收与回退.md`。

第三方项目及授权见 `使用说明/鸣谢与来源.md`。
