# 尖塔修补站 v0.11.8

修复从 v0.11.5 等旧版本点击「下载并更新」后出现“自动更新未开始：更新包不能写入个人数据或游戏目录。”、程序停留在旧版本的问题。

## 修复内容

- 发布包只包含 `manager-files.json` 中列出的程序文件及程序清单，逐一对照 SHA256 哈希，不再将构建和测试目录中的额外内容一起压缩发布。
- 构建输出中即便存在 `数据/`、个人设置、错误日志或其他无关文件，也不会进入 ZIP。
- 发布前再次检查 ZIP 只包含已登记的文件，避免生成能够下载但无法自动安装的更新包。
- 新增独立发布包测试，核对排除数据文件的行为及恶意路径拦截。

## 使用方法

现有 v0.11.5 用户可直接在「工具与设置 → 检查更新」检查并下载 v0.11.8，无需先安装 v0.11.7。也可以从 GitHub Releases 下载 ZIP，解压到独立目录运行。

## 安全说明

本次修复 **不降低** 自动更新器的限制；个人数据目录、游戏目录及任何未列入程序清单的文件仍不允许通过自动更新写入。自动更新会继续做包校验、程序备份和失败恢复，不修改游戏、MOD、存档和用户设置。

v0.11.7 引入的 GitHub MOD 更新检测与来源候选识别功能保持不变。
