# 尖塔修补站 v0.11.1

这是 v0.11.0 的小型兼容性修复，完整保留 MOD 更新检测、上游补丁确认和可恢复停用。

- 修正 `Mods` 根目录直接放置 MOD 的 JSON、DLL、PCK 时，健康检查错误把其他 MOD 子文件夹当作此 MOD 内容的情况。现在仅跟踪与根目录清单同名或同 ID 的对应 DLL/PCK，不误扫其他文件夹。
- 对含有子 MOD 的普通目录，也会跳过其他 MOD 自己的独立文件夹。
- 停用旧补丁时再次校验已审核的上游 DLL 指纹。预览后文件有变动，就拒绝执行并提示重新检查。
- 优化状态统计：没有上游修复证据的条目不再全部算作“需要核对”的警告。
- 新增根目录散放 MOD、跨 MOD 文件变化隔离、证据失效重检测试。

已通过独立 Windows CI 后才能发布。没有修改第三方 MOD 源码，也不会自动删除旧补丁。现有在线上游修复证据库仍为空，待人工核实作者更新后逐步录入；首次扫描仍只会建立基线。
