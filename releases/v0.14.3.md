# 尖塔修补站 v0.14.3 · 更新中心导航锁修复

本次修复 v0.14.2 进入「更新中心」后自动发起较长时间来源检查、导致全局导航和主题切换被锁住的问题。

## 修复内容

- **打开更新中心不再强制联网检测**：进入页面仅展示上次已保存或内存中的检测结果。点击「检查全部更新」后才开始读取 GitHub 与创意工坊更新信息。
- **更新检查与文件操作状态分离**：来源更新查询为只读网络操作，不再设置全局 `busy`；查询期间可自由使用左侧导航、「上一步」及其他无冲突功能。
- **支持取消检查**：查询进行中显示「取消检查」，避免重复发起相同的批量请求。
- **不会跳回更新中心**：后台检查结束、失败或取消后，只在当前页面仍是更新中心时刷新结果，不会覆盖用户后来打开的页面。
- **防止跨游戏目录的过期检查**：切换游戏目录或退出程序时取消正在进行的旧目录检查；只有 MOD 清单未变化时才公布本次统计。
- **保留原有安全保护**：MOD 的下载、安装、文件移动、备份恢复仍使用原来的文件事务锁、预览和校验流程，不改变这部分安全条件。

## 更新方法

打开管理器「检查更新」，选择「稳定版」，下载并更新 v0.14.3，或在 GitHub Release 下载 `SpirePatch-v0.14.3-win-x64.zip`。

## 已知限制

- GitHub 与创意工坊的部分下载或查询速度受网络、代理和接口服务影响；本版改变的是界面锁定方式，不保证第三方接口始终快速。
- 本版不变更 MOD 安装、签名与游戏分支兼容性规则，操作前请核对来源。
- 继续提供经典/新版布局和稳定版/Beta 更新通道选择。
