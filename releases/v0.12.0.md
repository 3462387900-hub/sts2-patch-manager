# 尖塔修补站 v0.12.0

本版将 Spire Glass 深蓝灰毛玻璃界面与 GitHub MOD 更新后的旧版本备份清理合并发布。

## Spire Glass 界面

- 主窗口更换深蓝灰配色，深色背景使用浅色文字，浅蓝实心按钮使用深色文字。
- 采用分层半透明侧边栏与卡片；Windows 11 22H2 及以上尝试启用系统 Mica 背景，其他环境保留渐变背景。
- 导航明确划分总览、模组管理、修复补丁、更新中心、联机检查、诊断与日志、工具与设置。
- 「更新中心」集中显示本地 MOD、GitHub 来源与更新状态，左侧列表、右侧详情，不改变已有来源核验及更新安装流程。
- 总览增加可更新 MOD、需要复核的修复补丁提示。MOD 列表行优化深色对比度与紧凑间距。

## 旧版本文件清理

- 普通 MOD 详情新增「清理旧版本备份」。
- 仅列出该 MOD 的较旧 GitHub 更新备份，不包含当前 MOD，最近一次备份始终保留。
- 用户手动勾选需要删除的备份并二次确认；不会自动删除，删除后该备份不可恢复。
- 清理前检查游戏已退出、真实目录在管理器专用备份区内、路径及符号链接安全。不符合条件则拒绝删除。
- 一次清理可能部分成功，界面会明确提示发生的错误；不会将部分成功误认为全部成功。

## 安全与兼容性

原有的 SHA-256 校验、MOD ID/版本核对、文件变动防护、联机对齐限制、补丁健康失效、安装备份与恢复机制均保留。不会因 MOD 更新而自动判定旧修复已经失效。

这是 Windows WPF/.NET 9 版本。透明材质具体效果会随 Windows 版本及透明效果设置变化；不支持时仍以深色背景保证可读性。
