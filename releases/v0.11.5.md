# 尖塔修补站 v0.11.5

本次更新修复 v0.11.4「模组管理」列表的按钮被隐藏问题，提升大量 MOD 和长中文依赖信息的可读性。

- **恢复操作按钮：** 在模组卡片右侧明确预留「详情」「更多」操作区域，长名称和依赖信息不再把按钮挤到窗口外。
- **卡片更容易识别：** 重点显示模组名称，次要信息显示 ID、版本和作者，启用/停用状态单独以标签表示，修复补丁使用不同的侧边标记。
- **依赖文字更清晰：** 对被其他 MOD 依赖的项目显示精简保护提示和数量，完整的依赖说明仍可在提示中查看；安全限制保持不变。
- **列表使用更顺畅：** MOD 列表单独滚动，顶部搜索、标签和状态筛选固定不动。搜索框新增可见提示，并显示当前符合条件的项目数量。
- **保留性能优化：** 继续使用 WPF 虚拟化/控件回收，不在每次输入时创建全部模组卡片。
- **回归验证：** 在 Windows 最小窗口 1020×720 下验证按钮坐标位于可视范围，测试超长依赖提醒、单滚动条、列表返回位置和模拟模组启停事务。

本版**不更新 MOD 修复载荷**，不会主动关闭、移动或删除游戏 MOD。文件启停仍使用原有确认、依赖检查与恢复流程。
