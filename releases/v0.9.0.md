# 尖塔修补站 0.9.0

联机检查从文字对比升级为可勾选的差异列表。导入队友清单后，以该清单为目标，诊断本机缺少、多出、已停用或版本不同的补丁。

- 逐项勾选、全选可处理项、清空选择；默认不勾选。
- 预览具体改动，一次确认后下载／安装缺失修复、移出多余独立补丁，或恢复匹配的已停用修复。
- 多余补丁保留完整文件，可在模组管理中恢复。原 MOD 内置修复不会被当作整个 MOD 删除。
- 确认前重新检查；文件变化、未知版本、缺少前置、共用目录、必要关联与队友目标不一致时停止处理。
- 逐步记录结果；失败停止后续步骤，保留已完成项及备份。完成后重新扫描，显示剩余差异。

## 使用方法

双方更新后重新导出清单 → 导入队友清单 → 勾选差异 → 退出游戏 → 预览一键处理 → 确认。

旧版 JSON 仍能查看，但一键处理需要双方用 0.9.0 或更新版本重新导出，才能区分实际缺失、已停用和原 MOD 版本不同。队友清单仍是导出时快照。

0.8.0 及更新版本可在「检查更新」中选择「下载并更新」。更早版本请完整解压 Windows ZIP 一次。

## 范围与验证

处理范围仍是本版已审核整合包中的修复。下载完整包，写入仅限所选及必要关联。原 MOD、存档与玩法配置不做全量同步。

隔离目录验证了差异分类、只读预览、混合安装与移出、预览后文件变化、文件被占用时保留已完成步骤、重试、恢复启用和安装回滚；实际 WPF 按钮验证勾选、全选、取消、确认及处理后刷新。既有扫描、推荐、下载与程序更新回归继续执行。测试未修改真实游戏或 MOD，未宣称完成真人联机验证。
