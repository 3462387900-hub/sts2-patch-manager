# 尖塔修补站 0.10.1

这是 0.10 系列的修复更新，不新增功能或游戏补丁，继续支持已收录的 17 项修复。

## 修复与改进

- 修复模组启停异常中断后扫描被停用记录阻塞的问题。核对原目录、停用区和完整文件哈希后补全事务记录；不搬移或覆盖模组文件，目录冲突、文件缺失或内容变化时保留现场并提示核对。
- 修复与当前补丁无关的重复模组 ID 未使扫描标记为不完整的问题，避免给出过于乐观的安装推荐。
- 限制联机清单导入大小为 2 MiB、每数组最多 512 项、文字和字段名最多 16384 字符、JSON 深度最多 32，避免异常文件占用过多资源；保留 UTF-8/UTF-16 BOM 清单兼容。
- 增加中断恢复、清单边界和重复 ID 回归检查。正式发布打包要求完整安装回滚、选择安装、模组工作台、联机对齐及十七项补丁事务集成测试全部通过。

## 更新方法

0.8.0 及更新版本可在「检查更新」选择「下载并更新」，也可完整解压本版 Windows ZIP。更新后重新扫描；联机双方有改动时重新导出清单。

这是管理器程序更新，不会自动安装或更新游戏补丁。

## 验证范围

Windows / .NET 9 下完成构建及自动化检查，所有游戏文件写入均使用隔离样本副本。GitHub 托管 CI 覆盖基础回归和模组工作台集成；依赖精确游戏/MOD样本的完整事务测试在本地发布打包时执行。未新增真人联机或完整对局验证。

涅奥重复排序键属于待验证的条件性风险，本版未改动该补丁算法。
