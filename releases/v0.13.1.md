# 尖塔修补站 v0.13.1 · 模组管理交互重构

本次更新重点改善本地 MOD 管理的导航层级与阅读体验；MOD 安装、更新、启停和环境恢复的原有安全确认流程保持不变。

## 主要改进

- **紧凑 MOD 卡片**：将卡片最小高度由 265 缩至 156，合并版本与作者等信息，保留启停、更新、更多操作和多选勾选；完整 ID、详细依赖等信息可通过悬停或详情查看。
- **一级 / 二级导航**：在「模组管理」加入「已安装 / 创意工坊下载 / 依赖关系 / 环境快照」统一二级标签，减少堆叠工具按钮；不再用「普通 MOD / 修复补丁」混合标签来回切换。
- **独立修复补丁管理**：本地修复补丁列表移动至「修复补丁 → 本地补丁」，保留补丁健康、整理、自动停用等既有功能。
- **右侧快捷详情**：宽窗口点击 MOD 名称显示版本、ID、作者、状态、依赖及安全启停预览，可进入完整详情；空间不足时直接显示完整详情。
- **创意工坊下载子页面**：支持直接粘贴 Workshop ID 或 Steam / 尖塔补给站分享链接；无效格式在页面中提示。有效输入进入现有下载、校验、预览和确认安装流程，不再额外打开输入窗口。
- **统一依赖与快照导航**：依赖关系分析、环境快照页面保持相同二级入口，减少返回与重复点击。
- **细节修正**：页面切换、文件变化后的列表刷新与筛选时快捷详情的收起逻辑同步调整。

## 更新方式

打开现有尖塔修补站，进入管理器「检查更新」，下载并安装 v0.13.1；也可在 GitHub Release 中下载 `SpirePatch-v0.13.1-win-x64.zip`。升级前请退出游戏；管理器会校验发布包及文件清单并保留失败回退路径。

## 验证与限制

- Windows / .NET 9 WPF 自动构建和隔离回归测试已经通过；本版还需使用者反馈真实窗口、系统缩放、卡片可读性及详情交互。
- 创意工坊 Manifest 签名验证及本机游戏分支匹配尚未完成；下载与安装仍需人工确认，只安装可信来源的 MOD。
- 依赖分析仅基于 MOD 清单和已知补丁声明，不代表可以检测所有运行时依赖。
- 环境快照不包含游戏存档、游戏本体、来源绑定和独立 MOD 历史备份。
- 保留 [尖塔补给站来源与鸣谢](../鸣谢与来源.md) 及第三方许可证说明。
