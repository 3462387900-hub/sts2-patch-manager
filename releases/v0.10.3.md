# 尖塔修补站 v0.10.3

## 修复：已安装的独立补丁无法整理
v0.10.2 在发现有效历史安装回滚记录时，会把所有已安装的独立修复补丁标记为“安全跳过”。如果页面显示“可整理 0 项，跳过 14 项”，本版针对这一情况修复。

- 现在会在整理前读取已安装批次的 `restore.json`，验证备份、相对路径与版本。可安全迁移的独立补丁仍移动到 `mods/_SpirePatch_Fixes/<补丁目录>`。
- 移动前保存原始回滚记录的完整副本；移动后只调整受影响记录的相对路径，不删除历史补丁备份。
- 记录整理事务；操作失败时尝试恢复目录和记录。发生进程中断时，管理器会阻止新的整理，并提供“恢复上次中断的整理”入口。
- 仍不移动普通 MOD、原 MOD 内置修复、未知文件、共用文件夹或校验不通过的补丁。

## 更新方式
在 v0.10.2 的“检查更新”中下载并更新，或从本 Release 下载 Windows ZIP。关闭游戏，并先备份 `Mods` 与 `mod_fix_backups` 两个目录，再运行“模组管理 → 整理独立补丁”，逐项确认预览。

## 验证边界
已通过 GitHub Actions Windows/.NET 9 构建和隔离自检，包括历史记录迁移、预览后修改拦截、损坏备份拒绝、BOM 兼容及中断恢复。尚未在真实游戏与多人对局中验证二级目录加载行为；遇到异常不要手动删除回滚备份。
