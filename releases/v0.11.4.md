# 尖塔修补站 v0.11.4

本版改善本地 MOD 目录的实时提醒与大量 MOD 时的列表流畅度。

- 当前选中游戏的 `mods` 与已停用模组存放区加入文件变化监测：新增、删除、改名或修改 MOD 文件时，将旧补丁健康结论标记为过期，防止误用之前的判断。
- 短时间内大量文件操作采用防抖机制（约 850 毫秒）。当前正在查看模组列表且没有文件事务时，自动刷新模组清单；其他页面会显示提醒，用户可进入模组管理刷新。
- 监测异常、通知缓冲区溢出或新建 `mods` 目录时会给出提醒，尝试重新绑定监测；遇到不确定情况仍需手动扫描。
- 列表使用 WPF 虚拟化与回收复用，仅创建可见项目的 UI 控件；搜索和筛选只更新数据，不再逐个重建所有卡片。
- 保留普通 MOD / 修复补丁双标签、补丁健康与查看依据、原有依赖限制及启停预览。
- 补充隔离测试：验证真实文件通知、缓存失效、自动清单刷新、160 行虚拟化，以及联机检查、文件事务等现有场景。

注意：文件通知是尽早提示变化的机制，不等于完整的 SHA-256 校验；仍需手动执行补丁健康检查。程序运行期间不建议整体移动或重命名正在监测的游戏安装目录，必要时请先关闭程序。本版本不包含新的第三方 MOD 或游戏补丁内容。
