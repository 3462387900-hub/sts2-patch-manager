# 尖塔修补站 v0.11.9

本版新增 GitHub MOD 一键更新与备份恢复，针对 RitsuLib 等能从 GitHub Releases 获取安装包的 MOD。

## 新增功能

- 在「模组管理 → 普通 MOD → MOD 详情」中绑定作者的 GitHub 仓库，点击「检查更新」；发现更高正式版本后显示「下载并更新」。
- 选择需要的 ZIP 附件（标准版、不同游戏版本兼容包需要自己确认），下载、校验、检查 MOD 清单并安装。
- 更新成功后，旧 MOD 文件夹完整保存在游戏根目录的 `尖塔修补站_MOD备份` 中；详情页提供「恢复上次 MOD 备份」。恢复前的版本也会保留备份。
- 支持识别仓库常用 `mod_manifest.json` 来源，过期候选将重新查找；GitHub REST API 限流时，版本检测尝试公开 Release 网页备用查询。

## 使用方法

1. 退出《杀戮尖塔 2》，进入管理器「模组管理」，打开普通 MOD 详情。
2. 关联可信 GitHub 仓库后点击「检查更新」。
3. 有更新时点击「下载并更新」，手动选择与当前游戏版本匹配的安装包，确认后执行。
4. 如果新版出现问题，关闭游戏，返回 MOD 详情点击「恢复上次 MOD 备份」。

## 安全与支持范围

- 必须是手动确认来源、已启用、位于独立 `mods/模组名` 文件夹下的 MOD；MOD 清单必须具有匹配 ID。
- 仅自动安装 GitHub 正式 Release 中具备 SHA-256 校验摘要的单 MOD ZIP。无摘要、源码 ZIP、多个 MOD 混合包、兼容版本不确定或非 ZIP 附件必须手动处理。
- 下载验证文件大小及 SHA-256；解压前限制路径、文件数量、解压大小、链接和不安全文件名；验证 MOD ID、版本及声明的 DLL/PCK。
- 替换前再次核对原目录文件指纹；游戏未退出、文件已变化或验证失败时不安装；安装过程中发生可捕获失败时尝试恢复原文件夹。
- 此版本**不提供** Steam 创意工坊匿名下载，也不保证所有 GitHub 发布包都支持自动安装。
- GitHub API 持续受限时可能只能检查版本，无法获取附件校验元数据，需稍后重试。
- Windows 托管 CI 已覆盖构建与隔离测试；尚未对每个第三方 MOD 实施真实游戏兼容性验证。建议首次更新前保留自己的额外备份。
