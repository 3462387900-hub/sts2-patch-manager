# 尖塔修补站 v0.11.2

本版以界面与操作体验改进为主，包含上轮完成但尚未发布的导航整理与补丁健康状态刷新。

- 「模组管理」按「普通 MOD」「修复补丁」分为两个标签页，分别显示数量，支持名称/ID/作者搜索，以及「全部 / 启用 / 停用」筛选。
- 已收录的独立修复补丁按补丁 ID 和同名清单归类，原 MOD 内置修复仍保留在普通 MOD 页。**分类只影响显示，不代表文件已通过校验。**
- 每行合并为「详情」和「更多」，在更多菜单中预览启用或停用、打开文件夹，避免大量按钮拥挤。
- 主侧栏精简为总览、模组管理、修复中心、联机检查及工具与设置；修复中心内保留补丁库、在线补丁、补丁健康和安装与回滚四个页面。
- 切换游戏目录、启停 MOD、整理补丁、安装与回滚、联机对齐及退役后，旧补丁健康结果与退役预览会作废，需要重新扫描，防止误用过期状态。
- 增加分类与页面导航的隔离验证，不改变已有的依赖、指纹、备份、回滚、事务锁和安装白名单流程。

本版不新增游戏修复载荷，不删除任何 MOD 或存档。文件操作仍需退出游戏，预览后确认。发布前使用 Windows 构建和隔离测试验证；真实游戏加载与多人实际对局仍需玩家验证。
