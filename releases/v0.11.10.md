# 尖塔修补站 v0.11.10

本版重点改进普通 MOD 的 **GitHub 来源自动发现**，不改变现有 MOD 一键更新、备份或恢复行为。

## 新增与改进

- 「模组管理 → 普通 MOD」新增 **批量查找 GitHub 来源**，每次处理最多 8 个未关联且没有近期结果的 MOD。重复点击会继续下一批。
- 自动发现综合 MOD ID、显示名称、作者及 GitHub 仓库简介进行搜索；查找前优先读取本地模组清单（包括 links / metadata）以及 README 中的相关 GitHub 链接。
- 找到仓库后，从 GitHub 公共原始文件地址检查默认分支的 `mod_manifest.json` / `manifest.json`，比对 MOD ID。确认不匹配的仓库会被排除。
- 列表和详情显示候选数量、证据等级与可能的搜索限制。所有来源都需要用户点击「确认关联」，不会未经确认自动绑定。
- GitHub 匿名搜索增加请求间隔及限流退避；成功候选短期缓存 6 小时，确实没有找到来源的结果缓存 30 分钟，避免反复请求。

## 使用方法

1. 先升级管理器至 v0.11.10。
2. 打开「模组管理 → 普通 MOD」，点击「批量查找 GitHub 来源」。
3. 进入提示有候选的 MOD 详情，核对候选仓库及核验说明后点击「确认关联」。
4. 如仓库存在更高版本的正式 GitHub Release，可继续使用 v0.11.9 已有的「检查更新 → 下载并更新」功能。

## 安全说明

- 只读取本地文本线索及公开 GitHub 搜索/清单，不读取或上传 MOD 的 DLL、存档或个人数据。
- 名称相似只提供候选，不等于已确定为同一 MOD。没有公开 GitHub 仓库或没有可核验清单的 MOD 仍可能查找不到。
- GitHub 搜索接口可能限流；在限制期间会显示可重试状态，不会将限流误判成“没有来源”。
- 不提供第三方创意工坊匿名下载功能，不改变原 MOD 文件，也不会自动下载 GitHub 候选仓库内容。

## 验证

- Windows/.NET 9 编译、现有隔离检查以及新增 GitHub 来源发现单元模拟测试覆盖查找逻辑；不代表已验证所有第三方 MOD 的真实来源和在线网络状态。
