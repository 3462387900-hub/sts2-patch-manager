# 尖塔修补站 0.10.0

补丁支持范围从 11 项扩展为 17 项，修复仓库已增加补丁、管理器仍使用旧快照和旧安装包的问题。

- 新增回合结束顺序、胜利滋生傲慢同步、悟空肘击目标、宁芙卡兹戴尔奖励、第三幕快照保存、涅奥选项顺序六项修复的推荐、选装、联机差异处理和回滚。
- 安装采用 v3 管理器专用载荷，仍校验精确原文件与包哈希。写入只限所选及必要关联；已有匹配文件跳过。
- 奖励修复核对宁芙前置；快照修复联动第四幕。已有联机兼容补丁按需协调，缺少时不会擅自安装。
- 新六项仅将 DLL 与模组 manifest 写入 mods，说明保留在仓库和缓存，避免游戏把描述 JSON 当成模组清单。
- 在线页区分目录数量与本版安装能力，下载提示区分管理器载荷与手动安装包。
- 增加中文补丁发布指南和默认只校验的发布脚本，核对发布附件、目录、说明快照及安装配方后才可切换正式源。

## 更新方法

0.8.0 及更新版本可在「检查更新」选择「下载并更新」，也可完整解压 Windows ZIP。更新后进入「在线补丁」刷新补丁源并重新扫描。联机双方更新后重新导出清单。

这是管理器程序更新，不自动安装游戏补丁。新增补丁仍需匹配对应 MOD 和精确构建；17 项为收录范围，不代表每位玩家都需要安装全部。

## 验证范围

验证覆盖新增六项逐项与组合安装、重复操作跳过、字节级回滚、关联选择、预览后前置文件改变、重复 MOD ID 拒绝以及联机缺失补丁补齐。旧版日志版本号兼容通过模拟 .1/.2 备份日志验证。继续执行原有选装、完整安装、扫描、下载、程序更新和联机规则测试。

所有游戏文件写入均在隔离目录进行；未修改真实游戏、MOD 或存档，未新增真人联机运行验证。既有补丁各自的验证边界仍以随附说明为准。
