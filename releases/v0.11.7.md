# 尖塔修补站 v0.11.7

本版为普通 MOD 增加 **GitHub 更新检测和来源自动查找**，不依赖 Steam 创意工坊或第三方 MOD 下载站。

## 使用方法

1. 打开「模组管理」→「普通 MOD」，点击「自动查找 GitHub 来源」。每次扫描最多 8 个尚未检查的 MOD，重复点击可继续处理后续 MOD。
2. 在发现候选的 MOD 卡片中点击「详情」，查看来源、匹配依据和候选仓库。可以先打开仓库核对，再点击「确认关联」。
3. 如果没有找到候选，可在 MOD 详情页选择「关联 GitHub 仓库」，手动输入公开仓库地址，例如 `https://github.com/作者/仓库`。
4. 点击单个 MOD 的「检查更新」或模组列表上方的「检查 GitHub 更新」，查看「有更新」「已是最新」「待核对」「无法检测」状态。
5. 发现更新后可以打开 GitHub Release 发布页，但当前版本不会自动下载、替换或安装 MOD。

## 核心约束

- 本版 **不自动关联候选仓库**。同名项目或分支可能不是实际来源，只有用户确认后才会写入关联。
- 仅检查公开 GitHub 仓库的最新**正式 Release**。只提供源码、Tag、预发布或私有仓库的项目可能无法检查更新。
- 本地 MOD 的版本格式若与 Release 标签不兼容，显示「待核对」，不会声称一定有更新。
- MOD 的 GitHub 关联存储于管理器数据目录，按游戏安装目录隔离，MOD 原文件和游戏存档保持不变。
- GitHub 匿名 API 有请求限制，批量搜索会做节流；接口故障不会阻止模组管理器的其他功能。
- 独立修复补丁继续使用原有补丁健康、指纹和退役判断，不以 GitHub 版本号代替修复依据。

已在隔离环境中执行 Windows 构建及自动化检查；真实游戏与不同作者仓库的实际识别覆盖率仍需用户验证。
