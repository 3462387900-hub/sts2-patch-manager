# 尖塔修补站 v0.14.0 Beta 1 · 双布局主题预览

这是**测试版**，用于对比两套界面布局、收集使用体验；不会进入正式版自动更新通道。

## 新增：侧边栏主题切换
在左侧「工具与设置」下方增加「界面风格 · BETA」，可即时切换两种布局：

- **经典 Beta**：沿用 v0.13.1 的模组管理页面结构、原有按钮导航、三操作按钮 MOD 卡片与六项筛选。
- **新版 Beta**：轻量二级标签、精简工具栏、组合筛选、紧凑整卡点击、右侧浮层详情和按需显示的底部批量操作栏。

切换无需重启程序。选择记入本地 `数据/界面主题.json`，下次启动沿用；不会更改游戏文件、MOD、修复补丁或快照。

## 继承的功能
保留 v0.13.1 的创意工坊下载、GitHub 来源检查、独立修复补丁、环境快照、依赖保护、停用安全预览、原有备份和回滚流程。快捷详情的常用操作依旧复用已有业务逻辑。

## 下载和使用
本版本是 GitHub **Pre-release**，下载 `SpirePatch-v0.14.0-beta.1-win-x64.zip` 并解压为独立文件夹测试，建议先退出游戏，保留原正式版目录以便回退。请不要直接覆盖正在使用的正式版文件夹。

正式版 v0.13.1 的「检查更新」**不会自动收到 Beta**，因为正式更新通道会过滤测试版。手动下载 Beta 后，可以在侧边栏随时对比两份界面。

## 已知限制
- 这次主要涉及「模组管理」及相关二级导航，**不是全应用各页面换肤**；下载与设置等页面保留统一深蓝灰毛玻璃基础视觉。
- 尚需人工验证实机不同 DPI、窄窗口、浮层遮挡和滚动观感；Windows 自动测试不能替代人工审美和完整联机验证。
- 创意工坊 Manifest 签名及本机游戏分支匹配尚未完成，只下载可信内容。
- Beta 不改变正式版自动更新索引 `manager-update.json`。
- 保留 [来源与鸣谢](../鸣谢与来源.md) 及第三方许可证说明。
