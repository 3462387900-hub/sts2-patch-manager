# 尖塔修补站 v0.12.3 · Spire Glass 视觉精修

在 v0.12.2 深蓝灰毛玻璃版的基础上集中优化视觉层级与 MOD 管理效率。此次更新不改变 MOD 文件操作、安全检查、GitHub 更新、备份与恢复规则。

## 五项视觉与可用性改进

1. **消除灰雾感：** 主内容背景恢复更深的冷蓝灰，适度增强深蓝色透明覆层（仍保留 DWM Acrylic 的通透空间），减弱蓝紫装饰光晕，避免大面积发白。
2. **柔和键盘焦点：** 将 WPF 默认点状焦点轮廓替换为圆角、浅蓝色键盘焦点装饰。键盘 Tab 导航仍具有明显可见焦点，不牺牲无障碍体验。
3. **明确按钮主次：** 「启动游戏」等核心动作保留实心浅蓝；MOD 刷新改为次级操作；普通 MOD / 修复补丁分组、全部/启用/停用筛选采用浅蓝半透明选中态，不再与主操作竞争。
4. **MOD 列表紧凑化：** 缩小顶部区域的空隙和每行内边距，合并 GitHub 与依赖提示为单行，保留悬停提示和详情中的完整信息；依赖关系采用中性「被 N 个已启用 MOD 依赖」，真正受限的操作依旧由安全逻辑阻止。
5. **减少导航边框：** 非选中项没有矩形边框，悬停时出现微弱背景，选中项使用深蓝半透明底色与 3px 左侧高亮条。

## 兼容与安全

- 沿用 Windows 11 DWM Desktop Acrylic 与 Alpha 合成诊断，不支持时自动回退为深色可读背景。真实模糊的视觉表现依赖操作系统及图形环境。
- 文字保持高对比度；深色按钮使用浅色文字，浅蓝实心按钮使用深色文字。
- 保留全部 MOD 更新、补丁健康、联机检查、依赖保护、旧版本备份清理与回滚机制。
- Windows 构建、隔离 UI 回归与 ZIP 运行数据排除检查是发布门槛；CI 无法完全替代用户机器的显示效果检查。
