# 尖塔修补站 v0.14.1 Beta 1 · 更新通道切换

本次 Beta 引入 **稳定版 / 测试版 Beta** 更新通道选择，在「检查更新」页面顶部直接切换。

## 主要变化

- **两个更新通道**：稳定版查询正式发布索引（必要时回退官方最新正式 Release）；测试版通过 GitHub Release API 查询已发布的 Beta，按版本顺序选择最新版本，不混用正式版。
- **主动选择**：切换后立即检查所选通道，保留是否下载和安装的决定权；选择保存于 `数据/管理器更新通道.json`，重启后仍生效。
- **安全限制**：草稿、错误标签、缺失 Windows 附件、非官方地址和 SHA-256 不正确的发布不会用于自动更新。仍需先校验 ZIP，再执行安装前安全检查。
- **不自动降级**：如果已安装 Beta 高于当前稳定版，不会把程序降级。相同三段主版本的不同预发布构建也不自动覆盖，避免突破更新助手的单调版本约束。
- **保留原有双布局主题**：左侧「经典 Beta / 新版 Beta」界面主题及 MOD 管理、修复补丁、备份恢复逻辑均保留。

## 升级说明

这是 GitHub **Pre-release**，不是正式更新通道推送的版本。

- 已安装 v0.14.0 Beta 1 的用户：旧版不具备 Beta 更新通道选项，**首次请手动下载并解压 v0.14.1 Beta 1**，之后可从新版「检查更新」选择测试版。
- v0.13.1 稳定版用户也需手动下载本 Beta；正式版不会自动推送测试版本。
- 建议解压到独立目录，不覆盖原来的正式版文件夹。手动迁移时如需保留设置，请在备份后复制自己需要的 `数据` 目录文件；不要覆盖 MOD 或游戏目录。
- 正式版 v0.13.1 仍是默认最新正式版，本次发布不会修改 `manager-update.json`。

## 限制

本次更新针对管理器的版本检查与下载，**不代表创意工坊 MOD 的稳定版/测试版分流**。实际网络下载仍受 GitHub 和本地代理条件影响。升级前请退出游戏与旧管理器。
