# 尖塔修补站 v0.12.1 · Spire Glass 毛玻璃修正

v0.12.0 虽然启用了深蓝灰主题，但 Windows 系统材质被高不透明度的 WPF 背景遮挡，实际效果看起来仍是普通纯色窗口。本次修正真实渲染路径，并保留原有所有功能。

## 材质修正
- Windows 11 22H2（build 22621）及以上：改为向 DWM 请求 Desktop Acrylic（真实桌面模糊），而非仅请求较弱的 Mica。设置 WPF 合成目标为透明、扩展 DWM 玻璃帧，修正此前背景覆盖系统材质的问题。
- 降低窗口覆层的深蓝灰色遮挡强度，在系统支持下让真实模糊透出；列表和内容卡片保留较高不透明度，确保浅色文字清晰。
- 为侧边栏、主要面板及 MOD 列表加入细微高光边框、透明层级和低强度环境光晕，增强玻璃层次。
- 支持时设置深色标题栏以避免系统蓝色强调色破坏视觉统一。
- 「工具与设置」增加材质状态说明：区分系统 Acrylic 请求成功与回退背景，不会把回退伪称真实桌面模糊。

## 兼容说明
- Windows 10、Windows 11 22H2 之前或系统透明效果不可用的环境：使用应用内渐变玻璃视觉回退，**不会呈现真正的桌面实时模糊**。
- Windows 11 即使请求成功，Windows 透明效果关闭、高对比度、远程桌面或图形环境限制等条件仍可能导致系统不实际显示 Acrylic。
- 实际毛玻璃表现需要在用户的 Windows 桌面上检查；GitHub Actions 的 Windows 构建与截图不能证明真实 GPU/DWM 毛玻璃视觉效果。
