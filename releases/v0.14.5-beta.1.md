# 尖塔修补站 v0.14.5 Beta 1 · 中文启动入口与未绑定 Workshop ID 筛选

本版继续作为独立 **Beta 预发布**，用于改进解压后的首次使用体验、加快建立公共 MOD 来源索引的人工绑定流程。稳定版自动更新通道保持不变。

## 更新内容

### 1. 中文启动入口

- 解压后在文件夹内可以直接双击 **`00-启动尖塔修补站.exe`**。这是完整的 Windows GUI 启动入口，不是失效风险较高的绝对路径快捷方式。
- 原始 `SpirePatch.exe` 仍然保留；两者运行相同的主程序，兼容现有更新器与脚本。
- 使用说明、更新日志、发布指南、鸣谢和第三方许可等文档现在集中放在 `使用说明/` 子目录。
- 暂时**不移动 .NET/WPF DLL 与运行时组件**：当前安全更新器依赖原目录布局。将所有运行库隐藏或随意搬动，反而可能造成启动或自动更新失败。此版先保证启动入口醒目且实际可用。

### 2. 「未绑定 Workshop ID」筛选

- 新版工作台在已安装 MOD 的状态下拉菜单里新增 **未绑定 Workshop ID**。
- 经典布局新增同名筛选按钮。
- 仅筛选尚未在当前游戏目录建立 Steam 创意工坊 ID 关联的**普通 MOD**，不会把独立修复补丁混入列表。
- 支持与搜索和启用/停用状态组合；筛选只读取本地来源缓存，不触发网络请求。
- 在 MOD 详情完成手动绑定后，筛选列表立即刷新；已经绑定的 MOD 不再显示在“未绑定”结果中。
- 与此前 v0.14.4 Beta 1 的手动 Workshop 绑定、公共 JSON 导出功能共同使用。

### 3. 继承更新来源改进

- 包含已通过隔离测试的 Beta 静态更新索引优先读取逻辑，避免每次检查都请求容易限流的 GitHub Releases API。
- 仍会验证 GitHub 官方附件地址、更新包大小和 SHA-256；不得绕过现有安装与回滚保护。

## 测试方法

1. 下载 `SpirePatch-v0.14.5-beta.1-win-x64.zip`，解压至单独的文件夹，双击最显眼的 `00-启动尖塔修补站.exe`。
2. 进入「模组管理 → 已安装」，新版布局打开状态下拉框并选择「未绑定 Workshop ID」；经典布局直接点击同名筛选。
3. 选择任一未绑定的普通 MOD，打开详情并手动关联 Workshop ID。
4. 返回列表观察该 MOD 是否自动消失。最后到「工具与设置」导出 `workshop-source-index.json`。

## 说明

- 本 Beta 不自动上传任何本地关联文件；导出的 JSON 需要人工审核后才能进入公共索引。
- 默认不会把内部 MOD ID 自动当作 Workshop 数字 ID，也不会将普通来源绑定当作远端版本校验通过。
- 建议独立保留以前的 v0.14.3 稳定版管理器，避免直接覆盖已在使用的目录。

项目第三方来源与鸣谢见 `使用说明/鸣谢与来源.md`。
