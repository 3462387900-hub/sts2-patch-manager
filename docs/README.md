## 根目录保护说明

以下文件仍必须留在仓库根目录，不属于本目录的迁移范围：

- `manager-update.json`、`manager-beta-update.json`：客户端固定 Raw URL。
- `catalog-plan.json`、`patch-catalog.json`：编译期内嵌资源及补丁源发布脚本输入。
- `鸣谢与来源.md`、`THIRD-PARTY-NOTICES.md`：发布包直接复制的来源与声明。
- `third_party/`：随程序分发的第三方许可证。
