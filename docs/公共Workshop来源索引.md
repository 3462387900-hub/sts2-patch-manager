# 公共 Workshop 来源索引 · 第一阶段

此阶段用于建立可人工审阅的 Steam Workshop MOD 来源关联数据，不包含自动云端下载、共享或上传功能。

## 在管理器中绑定
1. 进入「模组管理 → 已安装」，点击一个普通 MOD，打开右侧快捷详情或「完整详情」。
2. 选择「手动关联 Workshop ID」（已有来源时为「修改 Workshop 关联」）。
3. 粘贴 Steam Workshop 数字 ID、Steam 分享链接或尖塔补给站对应的分享链接。
4. 可以选择「核对条目」从尖塔补给站只读获取条目名称；**不会下载任何 MOD**。
5. 核对 MOD 名称/作者/条目 ID，勾选人工确认，再点击「保存手动关联」。

手动绑定复用原有本地来源文件。改变来源时会清除旧的版本验证基线；**不自动判定本地 MOD 已是远端最新版本**。

## 导出公共来源索引
1. 打开「工具与设置 → 导出公共来源 JSON」。
2. 阅读即将导出的条数与隐私提示，并选择保存路径。
3. 将导出的 `workshop-source-index.json` 发给维护者，审核后才提交 GitHub。
4. 请勿直接上传整个「创意工坊来源」数据目录，其中还包含针对个人游戏路径生成的文件名和版本基线。

导出只包含当前游戏目录、已经关联来源的普通 MOD；不会导出独立修复补丁。不同本地项共用内部 MOD ID、但名称/作者矛盾时不导出，避免公共索引误匹配。

## JSON 格式

```json
{
  "schema": 1,
  "app_id": 2868840,
  "mods": [
    {
      "mod_id": "ExampleMod",
      "name": "Example Mod",
      "author": "Example Author",
      "workshop_id": "1234567890",
      "verification": "local_binding"
    }
  ]
}
```

上例纯属示意，**并非已核实的 Workshop 对应关系**。

`verification: local_binding` 只表示该来源存在本地绑定记录，即使用户已人工确认，也不意味着管理器已读取并校验过远端 MOD 内部清单或本地内容版本。
