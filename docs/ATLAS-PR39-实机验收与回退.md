- [ ] 保留 PR38/旧 WPF 可用版本，确认能手动切回 `新版工作台` 或 `经典 Beta`。PR39 通过前不更新稳定版 Release 或 `manager-update.json`。

## 1. 显示与导航

| 场景 | 操作 | 通过标准 |
| --- | --- | --- |
| 小窗口 | 1020×720、100% 缩放 | 六个顶层入口、导航与操作按钮可达；重要文字不遮挡，页面允许滚动 |
| 常见桌面 | 1920×1080、100% 和 125% 缩放 | 列表占用大部分可用竖向空间；没有旧版 640px 固定高度与大片无意义空白 |
| 大桌面 | 2560×1440、100% / 150% 缩放 | 卡片按内容视口自动换列；打开右侧检查器不会水平裁切 |
| 高 DPI | 3840×2160、150% / 200% 缩放 | 控件、字体、菜单和提示正常缩放；触发区与显示区域一致 |
| 多显示器 | 在不同缩放比例显示器之间拖动窗口 | 列表高度和卡片宽度重新计算，焦点与滚动位置不异常 |
| 页面切换 | 总览→模组库→修复中心→更新中心→下载中心→设置 | 没有意外自动跳回旧版工作台；扫描期间仍可正常导航 |
| 主题回退 | ATLAS→新版工作台→ATLAS | 不丢失游戏目录、来源关联和操作结果；强调色与组件状态恢复 |

## 2. MOD 清单规模与输入一致性

| 数据规模 | 操作 | 通过标准 |
| --- | --- | --- |
| 0、1 个 MOD | 列表与卡片切换 | 空状态和单条卡片不会溢出或变形 |
| 24、25、100+ 个 MOD | 卡片分页、上下翻页 | 每页最多 24 项，页码正确；翻页后定位到本页首部 |
| 100+、500+ 个 MOD（如实机具备） | 列表滚动、搜索、按来源筛选、排序 | 列表继续采用行虚拟化；记录主观卡顿和耗时，不凭 CI 推断实际 FPS |
| 跨页批量勾选 | 在第一页与末页各选一个，再切页 | 选择数量与集合保持一致；批量操作遵守现有确认与安全检查 |
| 快速输入 | 输入关键词后立即点击“全选当前结果” | 按最新关键词对应的可见筛选集合操作，不错误选择旧结果 |
| 清除筛选 | 快速输入后立即清除，随即切换页面 | 无延迟搜索回流、无额外重选、不发生意外跳页 |
| 外部增删 MOD | 在管理器外增删隔离样本目录中的 MOD | 轻量清单刷新，失效选择自动清理；修复补丁健康结论不会自动变成“已验证” |

## 3. 下载安装与补丁安全

- [ ] 在下载中心输入非法 Workshop 链接，确保提示错误且**没有网络下载或文件写入**；有效 ID 只在主动点击后进入原有下载预检。
- [ ] 使用本人有权获取的一个 Workshop 来源，检查 Manifest/Chunk/版本与确认页；取消预览后检查游戏文件哈希未变化。
- [ ] 使用已有公开 GitHub Release 来源，测试检查更新、正常下载、预览安装与回滚；重点核查旧 MOD 备份是否按既有流程保留。
- [ ] 在扫描、批量启停、下载或安装进行中切换 ATLAS 页面，确保不会丢失操作状态或打开过期详情。
- [ ] 删除隔离样本中关联的 MOD，检查孤立补丁自动停用的**提示与文件保留**；不允许自动删除补丁文件。
- [ ] 对有清单读取/重复 ID 问题的 MOD，确保“预览启停”仍被禁用；“重新扫描 MOD 清单”只能通过真实重新扫描恢复，无需绕过安全拦截。
- [ ] 确认安装失败、用户取消和回滚后，原 MOD 文件、补丁状态与管理器数据符合现有事务约定。

## 4. 记录与通过门槛

记录环境：Windows 版本、分辨率、缩放比例、MOD 数量、PR39 HEAD SHA、运行模式（隔离样本/真实游戏目录）与测试日期。涉及具体网络与 MOD 文件问题时，保留必要的去敏感化日志及截图。

建议分别记录 **首次进入模组库耗时、100 个 MOD 搜索完成耗时、切换卡片/列表的主观响应、后台扫描期间界面是否可操作、管理器进程内存占用**。优先和同一设备的 PR38/旧 WPF 版本对比；不存在经验证的性能阈值时，不把预设数字写成已达成成绩。

严重等级：
- **P0 阻断**：非预期游戏文件修改、数据丢失、无法回滚、错误地绕过安全确认。
- **P1 阻断**：核心入口失效、窗口常用分辨率下无法完成操作、扫描导致持续跳页或卡死。
- **P2 待评估**：文案、间距、轻微视觉毛刺或不影响操作的低频排版问题。

**合并条件**：最新提交 CI 通过 + 上述关键真实客户端场景验收 + 无未解决 P0/P1 + 安全回退演练通过。完成前保持 PR39 Draft；不自动更改更新索引或发布稳定版。
